# 日報

日々の実装、実験条件、定量結果、判断、未解決事項、次回作業を日付順に保存する。
実験CSV、解析レポート、グラフ等は`Experimental_results/`を参照する。

各作業日の代表画像・グラフは原則2～4点を選び、
`Experimental_results/YYYY-MM-DD/report_assets/`へ保存する。カメラ画像は注釈、合成、切り抜き、
リサイズ、色・明るさ補正を行わず、元映像と同じ画角・解像度のフレームを使用する。
各資料の出典と用途は同フォルダの`README.md`へ記録する。
