## 2. 録画解析のワンコマンド化

`src/analyze_field_recording.py`を追加し、従来は複数コマンドで実行していた処理を統合した。

- アーカイブのSHA-256、構成、展開サイズ上限を確認
- 安全な一時展開と自動削除
- CSV連番、時刻、raw/BEV/detection動画とのframe数一致を確認
- 検出、観測採用、追跡、ODOM、実効FPSを集計
- 9区間の処理時間を集計
- 生映像から観測を再計算し、選択中のゲートを再生
- 事前要件と動的TTCプロファイルを指定した場合だけ正式PASS/FAILを出力
- CSV群と`analysis_report.md`を同時生成

事前要件を与えない解析は`DIAGNOSTIC`とし、遮蔽ラベルのない0/0イベントや、録画不足を
誤ってPASSと扱わないようにした。既存成果物の上書きも既定で拒否する。

## 4. 動的TTC評価条件

評価を次の2区間に分離した。

- 精度区間: 校正有効かつ`0.65 <= filtered_z <= 1.35 m`で、距離、速度、TTCを評価
- 警告安全区間: 最初の警告成立後から停止まで、`PATH`へ戻らないことを評価

主要な固定条件は、ODOM走行`abs(v)>0.05 m/s`、最小20 frame、相対速度方向95%以上、
接近中TTC発火80%以上、0.20 m/s時の警告開始TTC 3.5～4.0秒、警告後の前進中
`PATH=0 frame`、`CRITICAL=0 frame`、最終状態`CLEAR`である。
