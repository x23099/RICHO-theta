# 先端と観測下辺の対応改善（2026-10-21）

## 結論

生画像の同じX列に底候補を置く方法をやめ、先端と既知線分の投影方向が、**実際に観測された台座下包絡**と交わる列を選ぶ方法を実装・検証した。主案の左1.30 mは中央値1.206→1.258 mとなったが、静止中央2.00 mは2.135→2.138 mで改善しなかった。距離差の開発用目安は前回同様、両案とも8条件中7条件で達成した。

底候補を鉛直方向に対応させても、床上高さの大きな矛盾が残る。**点の選び方だけでは距離推定を完成させられず、本番FFBへの組込みは保留**。小さくなった線分残差は、選択と評価に同じ幾何を使う構成上の効果も含むので、正しい実接地点の独立検証とは扱わない。

正式な比較対象は **`results_r02/`**。予備計算の`results_r01/`は後述の処理監査前の保存物で、採用対象ではない。

## 処理した内容

前回保存した先端候補・全下包絡をハッシュ確認して再利用した。新しい色分割やYOLO推論はしていない。

仮想ピンホール座標で先端の視線をr_tip、床基準軸での既知線分をdelta、光学→床基準の回転をRとして、投影線を求める。

```text
delta_optical = R^T * delta
l = K^-T * (r_tip cross delta_optical)
```

この画像直線と観測下包絡が交わる位置の、最も近い**実観測整数画素**を底候補にした。既存支持範囲と同じ中央80%の列に限定する。隣接列での符号反転または実測点の直線上への一致を要求し、支持範囲外・2px超の欠損をまたぐ交点・複数の交わりは拒否する。見えない台座中心や隠れた交点の画素を作らない。

選んだ先端・底の視線を前回と同じ既知線分の最小二乗式で解く。床への強制投影、参照距離による点選び・係数fit、画素リサイズはしていない。

OpenCVの魚眼→透視座標との一致をテストした。ただしK/Dは従来の理想等距離仮定であって、新しい実測内部校正ではない。数学的な剛体変換を用いたオフライン解析であり、実TFノードを導入したという意味でもない。

参考：[OpenCV 魚眼モデル](https://docs.opencv.org/4.5.5/db/d58/group__calib3d__fisheye.html)、[カメラ投影モデル](https://docs.opencv.org/4.5.5/d9/d0c/group__calib3d.html)。直線選択規則と診断閾値は[事前固定条件](method.md)に記載。

## 推定率・残差・残る矛盾

6,876フレーム×3固定幾何×2案の**41,256行**を保存。主幾何の全録画では、旧同じX列方式4,969フレームに対し、主案4,963、奥行き差案4,961フレームで推定した。追加の見送り6／8フレームは、観測支持範囲内に投影線との交わりがないため。8評価区間では新旧の推定フレーム集合が一致しており、上表の改善は評価フレームを減らした効果ではない。対象なし等1,907フレームは元から観測先端または下辺がない。

選択した生画像X列の移動量の区間中央値は、主案1～6px、奥行き差案−4～+9px。奥行き差案の静止右では底候補Yも中央値−4px変わった。

線分残差の区間中央値は主案約0.8～5.1mm、奥行き差案約0.007～4.2mmに縮んだ。8評価区間の推定点は残差2cm以内だが、これは独立した物理点対応の合格数ではない。既知線分の張る平面に近い点を選んだため、残差が下がる構成になっている。

一方、主案の推定した底候補の床上高さ中央値は以下のとおり。**測定した台座の厚さではない。**

| 条件 | 底候補の推定高さ（m） |
|---|---:|
| 静止中央0.80／1.30／2.00 | +0.043／+0.082／+0.128 |
| 静止左／右1.30 | +0.085／+0.078 |
| 同一姿勢系列1.30／2.00 | −0.014／−0.017 |
| 10/19 2.00 | +0.246 |

特に10/19では、前方距離2.073 mと近くても床から約24.6cm浮く矛盾が残る。台座の内側の隠れた軸点と手前の見える辺の差、色境界と真の接地点の差、内部モデル・姿勢・床基準の不整合はまだ分離できていない。今回だけでカメラ取付変化や内部校正だけを原因と断定しない。

遮蔽時の縦寸法欠損で距離が過大になる問題も解消したとは言えない。[遮蔽・列移動のグラフ](results_r02/plumb_support_occlusion_and_shifts.png)に未補間の時系列を残した。
