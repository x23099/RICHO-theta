**録画の保存状態は正常。ただし今回の抽出結果では校正観測が不足し、K/Dのfitは行わなかった。** 窓の固定模様を校正へ混入させず、認識・サイズ・背景領域・重複の判断をすべて保存した。

## 角抽出の結果

全動画をdecodeし、5フレーム間隔と、冒頭150フレームの毎frame検索を合わせて689回試行。全2,844frameに角検出をかけたとの意味ではない。冒頭の密な探索は、大きい紙が見える時間を取りこぼさないため、fit前に固定した。

| 試行の結果 | 件数 |
|---|---:|
| 内角9×6を検出できず | 569 |
| 最小間隔8px未満 | 36 |
| 窓領域または重なりの曖昧候補 | 1 |
| 検出済みだが既採用と近重複 | 77 |
| サイズ・重複条件を通った候補 | **6** |
| 合計 | **689** |

内角9×6そのものを検出したのは120回。小さい検出36回の隣接角間隔中央値は約4.57～7.95pxで、既存の8px条件を満たさなかった。画像を拡大して8pxに見せかけたり、窓の固定模様を独立姿勢へ追加したりしていない。

固定模様の位置は目視に基づくnative矩形(175,220,55,80)付近。検出角群の中心がこの領域なら窓または重なりの曖昧候補として拒否した。除外1件を実際に窓だけだったと確定したわけではない。大きい前景の紙が窓を覆っても、角群中心が矩形外ならそれだけでは拒否しない。単一パターン検出なので、除外した同一frameに別の紙も検出可能かは保証していない。

6候補の原画像はすべて目視し、検出位置が人の手持ち紙に属することを確認した。窓候補の混入はこの6件ではない。[目視記録](diagnosis_r01/target_review.csv)。これはassistantによる原画像の対象識別確認で、撮影者による全54交点のサブピクセル検証とは別である。

## 校正・検証の扱い

20姿勢に届かないため、train/validation split・内部fit・ボード法線評価へ進めていない。実録画に対するK/D候補は作っていない。OpenCV solverを呼ばず拒否されることもテスト済み。[検証要約](verification_r01/summary.json)／[テストログ](verification_r01/test_log.txt)

共有PCの依存関係・GPU/ドライバー、元ファイル、本番設定、TF/ROS/FFB、安全ゲート、Git commit/pushは変更・実施していない。校正用ソースも変更せず、今回固有の背景除外は実験フォルダの補助scriptに分離した。
