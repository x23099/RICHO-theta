# 同じ床板撮影session内の赤コーン：概算1.5 mとの条件付き比較

作業日: 2026-10-30。**タイルからの概算1.5 mを追加情報として記録した。下端候補が得られたframe1655の水平距離はモデルによって1.40～1.53 m。概算と近い範囲ではあるが、正確な距離精度の検証ではない。frame1259は下端抽出を保留し、距離を出していない。**

続報: [左右枠接触に限定した下端候補の安定化](../../cone_lateral_completion_r01/README.md)を別モジュールで実装・検証した。frame1259の候補(299,385)も得られるようになったが、ライブへの接続や本報の保留結果の書換えはしていない。

## 距離の基準・入力

- ユーザーから、今回の2枚のコーンは「床タイル1枚50 cmなので、おおよそ1.5 m」と追加回答された。当初の不明という回答を更新し、**概算値1.5 m・不確かさ未提示・精密実測なし**として記録する。
- 概算1.5 mは、内部校正・床面・コーンの画素位置の最適化に使っていない。最も1.5 mに近いモデルを採用することもしない。
- 対象session `15ae673c24484d119952ae391df611aa`、frame1259/1655の無加工1280×720 PNG。同sessionの床板から得た法線だけを使い、別録画への幾何転用は行っていない。
- 床板296×210 mm、板厚は概算15 mm、レンズ中心床高さ590 mmは前報と同じ。
- 今回の出力は**カメラの床への垂線の足から、仮定した床上の下端候補までの水平距離**。レンズからの斜距離でも、車体座標系の前方Zでもない。未知の車体yaw・カメラと車体中心の対応を補っていない。

### frame1259を保留した理由

検出bbox左端280.665 pxから4 px拡張した切り出し枠の左境界は276 px。赤輪郭の左端も276 pxとなり、既存の接触拒否に該当した。一方frame1655の赤輪郭左端は278 pxで、同条件の枠内に収まる。ほぼ同じ静止画像でも採否が切り替わる例を確認した。

既存の余白24 px対照では、frame1259の赤輪郭の範囲は同じ `(276,302)～(325,385)` のまま接触がなくなり、候補点(299,385)も見える。しかし、**この対照の点を本判定の代わりに採用したり、保留画像の距離を救済表示したりしていない**。一律余白拡張を本番へ採用する根拠にもしていない。

この結果から、今後は校正とは別に、対象に対応する赤輪郭の抽出範囲と検出枠の小さな変動を既存データで検証する作業が必要。背景との連結や偽の下端を受け入れないことが前提となる。

## 同じ観測点での床面モデル比較

下端候補(300,385)が得られたframe1655だけを比較する。各床面モデルはコーンの概算距離を聞く前に計算済みの[固定内部校正による床面監査](../intrinsic_consistency_r02/README.md)から取得している。

| 床面モデル | 床法線の求め方 | 使用する床上高さ | 水平距離 |
|---|---|---:|---:|
| 紙面の高さも推定 | 高さ自由の共有床面 | 545.9 mm＋概算板厚15 mm | **1.451 m** |
| 実測高さを入力 | 紙面高さ575 mm固定条件から法線を計算 | 外部入力590 mm | **1.403 m** |
| 高さだけ置き換えた対照 | 高さ自由の法線を維持 | 外部入力590 mm | **1.526 m** |

最後の1.526 mが概算1.5 mに最も近いが、それを理由に採用しない。高さと法線の組合せを変えると約12 cmのモデル間差が生じることを示す対照であり、計測誤差12 cmを実証したものでもない。

[3モデルの距離比較グラフ](comparison_r01/validation_r01/conditional_cone_ranges.png)。根拠は `comparison_r01/conditional_ranges.csv` と `same_session_cone_comparison.json`。

観測点を各x/y方向へ±1画素ずらした数値対照も保存した。外部高さ＋高さ制約法線のモデルでは1.382～1.425 mとなるが、この範囲は実際の読取り誤差の信頼区間ではない。法線・内部校正・床接地の不確かさを全て含んだ精度保証でもない。

## 判断

1. 現画像内のコーンについて、既存録画内の床板と組み合わせて、条件付き距離計算まで実行できた。追加撮影はしていない。
2. 概算1.5 mと1.40～1.53 mが近いことは、極端な距離スケール違いが見えていない参考にはなるが、**距離誤差何cm、精度合格、校正転用成功とは判定できない**。
3. 下端抽出が2枚で安定していない。撮影時の従来マスクは2枚とも保留で、背景姿勢も従来条件では3／4平面にとどまり、必要な独立6平面へ届かない。今回のオフライン計算を実行できたから、現行のライブ表示が既に動くとはしない。
4. 条件付き床モデルの明示的な利用、色対応付き支持点の安定化、リアルタイム経路への接続、独立した距離真値による確認は、分けて進める必要がある。
5. 次に追加撮影なしで取り組める対象は、今回の枠接触を含む既存画像での支持点抽出の安定性検証。現在の拒否条件や校正を、この2枚だけを通すために変更していない。
6. `physical_metric_verified=false`、`floor_contact_verified=false`、`independent_accuracy_validated=false`、`live_integrated=false`、`usable_for_ffb=false`を維持。ROS/TF・FFB出力なし。
