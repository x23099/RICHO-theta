## 6. 起動手順

この計画書をcommitして作業ツリーをcleanにし、Kobukiと`/odom`を起動してから実行する。

```bash
cd ~/theta_ws/RICHO-theta

python3 src/run_field_experiment.py \
  --record-dir recordings/2026-09-03_ttc_candidate \
  --experiment-label pilot_odom \
  --config src/bird_eye_config_ttc_candidate_20260902.json \
  --dynamic-ttc-profile src/dynamic_ttc_evaluation_profile_v3_candidate.json \
  --camera-device 0 \
  --camera-fps 30 \
  --camera-frames 60 \
  --odom-topic /odom
```

preflightの全必須項目がPASSした場合だけアプリが起動する。pilotは青箱中央`z=1.0 m`で10秒録画し、
正式12試行へ含めない。アプリ起動後は`Trial label`欄を変更できるため、試行ごとの再起動は不要である。
