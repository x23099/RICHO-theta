# 実験結果と日次資料の保存規則

実験結果は`Experimental_results/YYYY-MM-DD/`へ日付別に保存する。

## 日報用資料

各作業日の代表画像・グラフは、原則2～4点を次へ保存する。

```text
Experimental_results/YYYY-MM-DD/report_assets/
```

`report_assets/README.md`へ、各ファイルについて次を記録する。

- 何を示す資料か
- 元録画または根拠CSV
- session名
- raw画像の場合はframe番号または動画内時刻
- グラフの場合は生成スクリプトまたは再現コマンド

## カメラ画像

- `raw.avi`などの未描画映像を使用する。
- 注釈、枠、文字、複数画像の合成を加えない。
- 切り抜き、リサイズ、回転、色・明るさ・コントラスト補正を行わない。
- 動画から取り出す場合は、デコードした元解像度の1フレームをPNGで保存する。
- 対応する録画名、session、frame番号または動画内時刻を必ず残す。

## グラフ

- 解析CSVなど測定値を根拠として作成する。
- 軸名、単位、凡例を付ける。
- 元データと生成方法を追跡可能にする。
- スライド向けの見栄えより、測定結果を正確に表すことを優先する。

カメラや実験データへアクセスできない日は、無関係な画像を代用しない。適切な資料を作成できなかった理由を
日報へ記載し、後日データへアクセスできた時点で追加する。
