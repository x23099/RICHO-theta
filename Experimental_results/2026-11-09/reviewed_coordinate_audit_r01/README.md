# 人の確認座標による床・台座辺の分離検証（2026-11-09）

## 結論

ユーザーが既存6枚を確認した座標を読み込み、紙角だけの置換と台座支持点の置換を分けて検証した。**同じ録画の自動支持点を一切変えなくても、紙角を人の確認値へ置き換えると1/1.5/2mの中央値が約0.995/1.482/1.984mへ改善した。** 紙外周の抽出を改善すべき根拠が得られた。

一方、紙から推定した高さと申告59cmは完全には一致しない。台座辺の物理対応、紙の縦横対応、カメラ直下と測距原点の対応も未確定。**「誤差2cm以内の距離推定が完成」とは判定せず、live/FFBへ採用しない。** 距離を正解へ合わせるフィッティング、別録画への校正転用、安全条件緩和、実行時変更は行っていない。

- 申告値の持越し：紙296×210mm、板＋紙の厚さ約15mm、レンズ中心の床上高さ590mm。今回の再測定ではない。

- 全6画像・確認JSON・元ログ・旧校正をSHA256に固定し、前後で不変を検査。人のクリックの小数桁数は、その精度や床接触の保証ではない。
