# 紙角の微小ずれと床・距離推定の感度（2026-11-09）

## 結論

**現在の小さな床紙では、四隅の1px程度の差が、遠方の推定距離を数cm変え得る。** 前回の確認座標による1/1.5/2mの一致は改善の証拠だが、それだけで「実距離誤差が約2cm以内」とは判定できない。

df33の左上角のY座標だけを±1px動かし、それ以外の紙角・コーン支持点・内部校正を固定すると、同じ遠方フレームの距離は **1.911～2.064m** に変わった。高さも **530.40～571.00mm** に変わる。今回これは実測誤差の測定ではなく、座標を意図的にずらしたオフライン感度試験である。

元画像・人の確認JSON・live設定は変更していない。新たなライブ用床bundle、ROS/FFB設定、学習モデルは生成・変更していない。追加撮影やユーザー側の操作はまだ依頼していない。

## 対象・方法

前段：[人の確認座標による分離検証](../reviewed_coordinate_audit_r01/README.md)。同じ6画像と6決定JSONをSHAで固定した。

- 紙画像：b559 / frame5755、df33 / frame2292。native 1280×720の左レンズ。人の確認した白紙外周4隅を基準とし、別session間で床モデルを混ぜない。
- 296×210mm、厚さ約15mm、高さ590mmは持越し申告。紙の縦横はunknownなので2対応・平面解2通り・高さ2方式を全件維持。
- 固定支持点：b559 f35562=[308,417]、df33 f61948=[315,419]、f64232=[316,373]。b559 f32654=[308,419]も参考計算するが、これは**実行時に拒否された候補点でlive出力ではない**。
- 各session **573ケース**：基準1、1座標だけ±0.25/0.5/1pxの48、四隅すべての平行移動12、全8座標を各々±0.5px/±1pxとした全符号組合せ256×2。
- 全8仮説を毎回保存し、計 **9,168モデル応答**。IPPEの生の解番号と、基準法線との角度連続性で対応させた解系列を両方記録。対応付けに高さ59cmや距離の正解ラベルを使っていない。今回、生番号の入替は0件。
- 紙角の移動をノイズ分布・発生確率と仮定しない。符号組合せの最小/最大は**試した点の応答範囲だけ**で、信頼区間でも連続領域全体の上限保証でもない。
- 画像はメモリで読んで計算するだけで、カメラPNGの注釈・切り抜き・リサイズ・補正・再保存は行わない。グラフのみ別ファイルに生成。

## 3. 旧自動抽出の再現と閾値依存

以前から明示されていた紙ROIをそのまま使用し、gray閾値150/170/190 × `approxPolyDP`係数0.02/0.025/0.03/0.04を各画像で試した。全画面から紙を自動発見する試験ではない。生画像へ処理結果を描き込んでいない。

|対象|試した設定数|4頂点の凸四角形が出た設定数|4頂点にならず保留|
|---|---:|---:|---:|
|b559|12|4|8|
|df33|12|9|3|

旧主条件b559=170/0.025、df33=170/0.02を再現し、保存されていた旧4隅に完全一致した。したがって前回との差は、別画像・座標系の取り違えや再現不能な旧処理から生じたものではない。

- b559の旧主条件は人の左上角から約3.68px離れている。閾値190/係数0.04では最大約5.18pxの差となる。白紙と反射がつながる境界で、4頂点が得られたこと自体は紙角の正しさを保証しない。
- df33の旧主条件の最大角差は約1.07px。今回の12条件内で4頂点を得た設定を比較すると、同じ遠方支持点の距離は約2.059～2.392m、高さは約462.13～550.06mmに変わった。
- 人の座標へ一番近い閾値や、実測距離に合う設定を新しい正解として選んでいない。失敗した11設定は推測4点で補完せず、そのまま保留を記録した。

根拠：[contour_scan.csv](results_r02/contour_scan.csv)、[実際に観測した四角形の座標](results_r02/contour_coordinates.json)。画像内で4角を最も近い順に都合よく入れ替えて誤差を減らしていない。今回ROIの画像上の左上から、画像座標の正の面積順に並べる固定則を用いた。

## 判断と次の一手

1. **紙角を確認し直した意味はあった。** 旧抽出との差を再現でき、遠距離に強く影響する方向も定量化できた。
2. **前回の約2cmの一致を、システムの誤差保証に使わない。** 高さだけ590mmへ固定する方法も、法線誤差を解消せず、別仮説のままである。
3. **閾値を変更するだけのlive修正は見送る。** 正解ラベルに合わせて閾値を選ぶのは同じ画像への調整で、未知画像での改善を示さない。現行live設定・安全条件は維持する。
4. 続編の [紙外周・角補正の安定性検証](../paper_boundary_stability_r01/README.md) で、画像の境界証拠、OpenCVサブピクセル補正の初期位置・閾値依存を検証した。安定化する例は得られたが、物理高さ・距離の一致は未解決で、live採用は見送った。既存紙は投影が小さく、画像にない細部をサブピクセル処理だけで保証することはできない。追加撮影が必要と判断する場合も、単に同じ条件の撮り直しを求めず、**必要な角の視認性・独立した床姿勢情報**に不足を限定して相談する。
