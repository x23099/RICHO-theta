# 比較処理併用の短時間・低速走行確認

2026-11-13。ユーザーが「つづけましょう」と回答。静止実映像r02は終盤30秒901件の数値・主比較一致、正常終了まで確認済み。次は同じ実装で比較処理を併用した走行時の更新・保留・負荷・失効を確認する。こちらからROSや機体は起動しない。

- 測距runtime・距離式・閾値・床profile・操縦経路を変更しない。現地の操縦者が従来の操作で最低速・短距離の直進と停止を行う。診断数値を制御・停止判断に使わず、接触／遮蔽を意図的に起こさない。
- 前回の受信は終了済みなので新規sessionが必要。新規3保存先で通常受信・送信→現在native画像をpin→3点コピー提出→こちらで現在画像の境界参照を準備→同接続でload、という順序を守る。前のJSONのsession書換え転用をしない。最初はpin提出まで。
- 対象は赤コーン1本、他候補を最初から外す。取付後のカメラを終了まで外さない。固定取付／床姿勢未検証・姿勢補償なしという制約を維持する。今回は精度誤差や自動回避の完成試験ではない。
- load後に主画面の距離欄・session/frame・映像が入る短い画面録画を行い、停止→低速直進→停止を記録する。前回一時値8件の再発時の状況を確認するためで、独立実測やnative画素の代替にはしない。意図的に手等でコーンを遮蔽しない。
- 既存のbounded native evidenceも明示ONにする。ただし対象はcolour_contour_reaches_roi_edge保留だけで、数値の一時変動を自動保存する機能ではない。最大40組・128MiB・1秒間隔。追加writer込みの負荷を今回のログで確認する。
- 終了後、主出力・比較・evidenceの3フォルダと画面録画を提出。未使用範囲外・候補複数・遮蔽・鮮度切れは保留のままにし、解消するための閾値緩和や主表示への比較接続は行わない。
- 手順はshell構文と実CLI parserで確認する。既存runtimeテストの無意味な再実行や未依頼の日報／commit/pushは行わない。
