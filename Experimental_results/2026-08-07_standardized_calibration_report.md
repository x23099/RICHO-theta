# 配置基準統一後の青色障害物キャリブレーション評価（2026-08-07）

## 結論

- 配置基準を統一したcalibration 6地点とholdout 4地点を解析した。全地点の青箱検出率は100%だった。
- 現在の実装で表現できる補正形式では、holdoutの2次元位置誤差が平均5.82 cm、最大8.86 cmだった。
- 2次元アフィン補正では、calibration誤差は平均1.63 cm、最大2.66 cmまで低下した。一方、独立holdoutは平均5.84 cm、最大8.20 cmだった。
- 事前合格条件の平均5 cm以下・最大8 cm以下に対し、それぞれ0.84 cm、0.20 cm超過したため、厳密には不合格とする。
- 距離だけの誤差は平均2.39 cm、最大3.64 cmで良好だが、経路交差判定には横位置が必要なため、距離だけで合格にはしない。
- `bird_eye.py` と `bird_eye_config.json` は変更していない。

- 全地点の検出率は100%。解析に使用した安定区間は各地点96～209フレームだった。

## 解析方法

1. 各CSVの先頭30フレームを除外した。ただし119フレームの録画は先頭20%（23フレーム）を除外した。
2. `detected=1` かつ `area_px>=2000` のフレームを有効とした。
3. 録画時間による重みの偏りを避けるため、各地点の `raw_x_m`, `raw_z_m` の中央値を1標本とした。
4. calibration 6点だけで係数を推定した。holdout 4点は係数推定に使用していない。
5. 現行実装互換形式と2次元アフィン形式を比較した。

## 補正モデル

### 現行実装互換

```text
x = 0.762922981 * raw_x
z = 1.195265719 * raw_z - 0.233648328
```

### 2次元アフィン候補

```text
x =  0.765663260 * raw_x - 0.022286670 * raw_z + 0.013415026
z = -0.095818095 * raw_x + 1.238450202 * raw_z - 0.278146307
```

## 次の実験

今回の10地点は撮り直さず、次回は次のように扱う。

1. 現在のcalibration 6点とholdout 4点を合わせた10点を、横位置を含む拡張calibration集合へ昇格する。
2. この10点を使った2次元アフィンのleave-one-out診断は平均4.68 cm、最大7.65 cmで、追加検証へ進む価値がある。ただし独立holdoutではないため、最終合否には使わない。
3. 新しい独立holdoutとして、`x=±0.22 m`, `z=0.95/1.20 m` の4地点を録画する。
4. 推奨フォルダ名は `holdout_xm0.22_z0.95`, `holdout_xp0.22_z0.95`, `holdout_xm0.22_z1.20`, `holdout_xp0.22_z1.20` とする。
5. 箱の端と面の基準は今回と同じにし、各5～8秒録画する。カメラと設定は変更しない。
6. 拡張calibration 10点で係数を推定し、新holdout 4点で平均5 cm以下・最大8 cm以下を満たした場合のみ、補正式を実装する。
