## 結論

依頼された3項目のオフライン検証を完了。元画像・校正値・実行時の判定・ROS/FFB経路は変更していない。

1. 紙の上辺に296mm、奥行き方向に210mmを対応させる `as_listed` の方が、その逆より申告高さ59cmと整合する。ただし、紙角の読取り対照で推定高さが大きく変わり、59cmに近い1候補を自動採用する根拠にはしない。
2. `df33e833` の1/1.5/2mと、`b559e424` の1mを**それぞれのモデルのまま**再確認。前者は正方向の差が遠方で増え、後者は1mで負方向の差。共通オフセットやモデルのセッション間転用は行わない。

## 1. 紙の寸法と高さ

### 方法

3セッション・8組の四隅観測（主仮説と既存の読取り対照）から、32個の平面解を再計算し、保存済み解と一致を確認した。

白紙296×210mm、板＋紙の概算厚さ15mm、申告レンズ高さ590mmを用いる。紙面と床は平行で床に置かれているというユーザーの前提に従い、画像由来の紙面高さへ15mmを加えて床高さと比較した。外部高さ590mmを最初から代入したモデルを「高さが合った」と評価する循環は避けた。

別検査として、各画像法線を固定し、申告に基づく紙面までの高さ575mmで四隅の光線を紙面へ交差させ、復元した4辺と296/210mmの対応を比較した。高さや法線を再fitしていない。板厚・高さの測定誤差は未指定なので、合否閾値や信頼区間を新設しない。

### 主仮説・解0の結果

|session|as_listedの床高さ|590mmとの差|swappedの床高さ|590mmとの差|
|---|---:|---:|---:|---:|
|9b7d9a17|501.87mm|−88.13mm|188.67mm|−401.33mm|
|df33e833|528.70mm|−61.30mm|197.94mm|−392.06mm|
|b559e424|581.72mm|−8.28mm|215.84mm|−374.16mm|

`swapped` は紙サイズと申告高さを同時に説明しにくい。最新b559e424では、申告高さで復元した4辺はas_listedが **318.1 / 207.1 / 284.0 / 221.3mm**（対応期待296/210/296/210mm、辺残差RMS13.87mm）、swappedが **701.9 / 822.1 / 510.4 / 894.3mm**（期待210/296/210/296mm、RMS491.66mm）。ただし、どちらも完全な物理四隅の証明ではない。

### 一意化できない点

- b559e424のas_listed解0は、既存の別閾値対照で床高さ **581.72→648.15mm**。df33e833の対照範囲は **462.13～550.06mm**。対照は画像読取りの感度であり誤差分布や信頼区間ではない。
- b559e424のas_listed解1も高さ572.39mmと59cmに比較的近い。しかし法線は解0と大きく異なる。高さの近さだけで平面解を選べない。
- 法線について画像上の仮の上方向 `[0,-1,0]` からの角度も記録したが、これは実測重力ではない。別セッションの法線を正解として移植していない。
- 四隅の順序から平面座標の法線符号が逆になるため、導出器はカメラ側を上向きとして符号を揃えている。保存IPPEの負の符号付き高さを、そのまま「カメラが床下」と解釈しない。

最新主候補が高さ整合性で比較的よいことは確認できた。しかし反射とつながる紙角や平面解の不確定性が残り、既存映像だけでは物理床モデルを唯一確定できたとは言わない。距離実測を使って候補を選択したり、導出済みbundleを上書きしたりしていない。
