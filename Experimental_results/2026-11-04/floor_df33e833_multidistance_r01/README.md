# 同じ床モデルのまま1.0 / 1.5 / 2.0mを比較

## 結論

提出された新しい2地点と先行1.50mのログを合わせ、同一session・同一generation・
同一床モデルで3配置を比較できた。追加撮影前に、距離依存の差と近距離の支持点欠落を診断できる。

**as_listed解0の紙面寸法＋厚さモデルが3地点とも申告距離に最も近いが、
遠方で差が増え、1mでは比較値が13.5%の処理行で保留された。完成・走行/FFB承認とはしない。**

## 近距離の保留と遠方の画素感度

1mは支持点なし65行、支持点の再確認待ち16行の合計81行で数値保留。
loader失効やフレーム鮮度切れではなく、支持点観測と品質の条件による。
最長の連続保留はframe61631～61661、30行。最初の保留から次の数値復帰まで約1.029秒。
補完は6行で試みられたが許可は0行。ログの理由には
`not_lateral_only_contact`、`completed_point_outside_original_bbox` があり、
それらの安全条件を今回解除していない。

2mでは全行で比較値ありだが、支持点y=373の589行とy=371の11行で値に差がある。
後者11行の主候補は約2.250～2.251m。
1mでも支持点y=417の472有効行は中央値1.026m、y=419の47有効行は中央値0.999m。
遠方ほど小さな画素変動が大きな距離変動へつながる様子がこのログから読み取れる。
ただし支持点が物理的な接地点であるとはまだ認定していない。

受信から計算完了までの経過時間の最大は1mで70.02ms、2mで56.19ms。
500msの上限内。撮影からの通信遅延を含むend-to-end時間ではない。
