# 動的TTC評価条件の固定

## 結論

動的TTCの評価を、次の2区間に分離した。

1. **精度区間**: 距離・速度・TTCの定量精度を採点する。
2. **警告安全区間**: 警告成立後から停止まで、観測が不安定でも`PATH`へ戻らないことを採点する。

これにより、校正下限`z=0.65 m`以近の位置反転を速度精度に混ぜず、同時に、
警告後のTTC消失を安全扱いする回帰も防ぐ。条件は
`src/dynamic_ttc_evaluation_profile.json`のスキーマ版1として固定した。

## 評価区間

### 0.10 m/s接近・後退

- ODOMが期待方向へ`abs(v)>0.05 m/s`の区間を走行中とする。
- 校正有効かつ`0.65 <= filtered_z <= 1.35 m`のフレームを精度採点する。
- 接近ではTTC発火、後退ではTTC誤発火を採点する。
- 4秒警告へ到達しない計画なので、生・フィルタ後警告は0フレームとする。

### 0.20 m/s接近

- 精度採点は、校正有効範囲に入った走行フレームから最初の生`WARNING`までとする。
- 最初の`WARNING`は停止操作開始点であり、それ以後の前進フレームは速度精度に含めない。
- 一方、警告状態は停止までの全フレームを再生する。前進中の無効観測は有限`WARNING_HOLD`後に
  `UNKNOWN`とし、`PATH`には戻さない。

## 固定した合格条件

| 項目 | 条件 |
|---|---:|
| ODOM走行判定 | `abs(v) > 0.05 m/s` |
| 校正範囲 | `0.65–1.35 m` |
| 最小精度区間 | 20 frames |
| 検出率 / 追跡率 / ODOM率 | 98% / 95% / 95%以上 |
| 実測速度p90の名目値誤差 | `max(0.025 m/s, 20%)`以下 |
| 直進性 | ODOM `abs(angular.z)` p95 <= 0.10 rad/s |
| 相対速度方向 | 95%以上 |
| 相対速度MAE | `max(0.03 m/s, 実港速度の20%)`以下 |
| 接近中TTC発火率 | 80%以上 |
| TTC発火遅延 | 0.50 s以下 |
| 後退中TTC誤発火 | 1%以下 |
| 0.20 m/s警告開始TTC | 3.5–4.0 s |
| 3 frame確認後の警告成立遅延 | 0.15 s以下 |
| 警告保持 | 1 frame以上、最大0.8 s |
| 警告後・前進中`PATH` | 0 frames |
| `CRITICAL` | 0 frames |
| 最終状態 | `CLEAR` |

`UNKNOWN`のフレーム数には上限を設けない。`UNKNOWN`は安全または合格の証拠ではなく、
実験者が停止すべき不明状態である。検出・追跡・精度区間の下限は別途必ず満たす。

## 古い録画の扱い

8月18日録画は動的TTC条件には9/9 PASSしたが、現在の厳密な一括解析では次が残る。

- カメラ要求30 fpsに対し、実効は約25 fps。
- 旧CSVの`time_sec`と`monotonic_time_sec`は同一値ではない。
- 静的録画用の外れ値回帰判定は、移動を外れ値と数えるため動的録画には適用しない。

これらを隠さないため、回帰台帳では「アーカイブ総合FAIL」と「動的TTC全試行PASS」を
別カラムで固定する。この再評価は過去録画に対する開発回帰であり、
30 fps化後の新規動的holdoutの代替ではない。

静的2データセットと動的2データセットを合わせた全回帰は4/4データセットPASS、
FAIL 0、SKIP 0である。ここでの回帰PASSは、既知の総合FAILを含めて登録時点の振る舞いと
一致したことを意味する。

## 実行方法

```bash
python3 src/evaluate_dynamic_ttc_conditions.py \
  --input /path/to/recoding_08181725.tar.xz \
  --input /path/to/recoding_08181740.tar.xz \
  --profile src/dynamic_ttc_evaluation_profile.json \
  --output Experimental_results/2026-08-28_dynamic_ttc_fixed_evaluation.csv
```

録画回帰では`run_recording_regression.py`がプロファイルを自動適用し、
`expected_dynamic_sessions`/`expected_dynamic_pass_sessions`を照合する。
