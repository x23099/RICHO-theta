## 3. 繰り返し見えた線をまとめる別方式も比較

単に画像枚数だけを増やす試験を繰り返さず、同じ録画・同じ時間半分の中で平面をまとめる対照も実施した。固定seedと2度以内でgroup化し、1frameにつき1票、異なる3frame以上で繰り返し見える安定平面だけを使う。3frame分を3本の独立した線に水増ししない。

この集約後も独立6平面等の元の空間条件を保持し、前半と後半で独立に方向を求めた。結果は系列が前半6／後半7 inlier平面、方向差0.135度で候補取得。他の録画は概ね4～5平面、10/19は推定側の安定平面不足で、1/9のままだった。

推定単位を1画像から安定平面集合へ変更した別方式であり、元と全条件が同じという説明はしない。静止姿勢という仮説を用いるため、そのまま走行中の姿勢推定へ導入するものではない。

## 6. 数cm精度・本番使用をまだ保証しない理由

1. **姿勢候補の違いによる感度が残る。** 評価側で条件を満たした8画像それぞれのup方向を、同じ実観測下端へ適用すると、1.30 m条件は**1.3248～1.4023 m**、2.00 m条件は**1.9719～2.1317 m**となった。この範囲は候補の使い替えによる経験的感度であり、統計的信頼区間・真の誤差上限ではない。平均姿勢でp95が約2 cmでも「常に2 cm精度」とは言えない。
2. **他8録画の方向は未取得。** 画像増加・安定平面集約の両方で未達を残した。白紙7点と10/19の紙2 mへ、成功録画の姿勢を使うfallbackはしていない。追加の幾何比較は未推定として保存した。
3. **高さ法は未解決。** 同じ主姿勢で高さ73 cm・垂直端点仮説は、1.30 m設置で約1.434 m、2.00 m設置で約2.204 m。底点は床下約4.62/6.59 cm。物理端点対応の課題を、床交点の中央値が近いことだけで解消したとはしない。
4. 建物線が厳密に鉛直、床がその鉛直に直交することを測量したものではない。画像ROI・consensusという検出器側の不足を、既存映像に物理情報が全くないという結論にもしていない。
5. 静止・単一コーン中心の開発データ。複数コーン、走行、照明・背景変化、検出の誤り、距離の運用範囲、リアルタイム性と実機安全は別途検証が必要。
