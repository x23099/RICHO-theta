# 10/22継続作業：建物線の除外段階監査と解析範囲の対照試験

## 結論

**姿勢候補が得られない主な停止箇所を、画像不足という説明から、候補線の選択と最初の方向一致判定まで絞った。**
凍結した元処理では492枚中、方向一致不足319枚・独立候補不足146枚・採用27枚。
方向一致不足は全て最初の候補方向で2～5平面しか一致せず、SVDによる再計算へ進む前に停止していた。

ROI下端だけをy=300→430へ広げる対照では、時間を分けた再現性条件を通る録画が**1/9→5/9**になった。
一方、元の成功録画は通らなくなったため、**本番の範囲は変更していない**。
この5録画は条件付きの画像姿勢候補であり、真の鉛直・距離精度・FFBの検証成功ではない。

ユーザー指定どおり全て**2026-10-22分**。録画名に含まれる10/15・10/19は変更していない。
新規録画、距離への新方向適用、YOLO推論/学習、ROS/TF配信、実機/FFB、設定更新、Git commit/pushは実施していない。
全成果物は`usable_for_ffb=false`。

## 2. 元の処理のどこで停止したか

| 最終状態 | 画像数 | 停止位置 |
|---|---:|---|
| 独立平面が6本未満 | 146 | 方向候補の組合せ探索前 |
| 方向一致する平面が6本未満 | 319 | 最初の方向候補の選択後、SVD前 |
| 条件付き方向を採用 | 27 | 最初の6本が2回の再計算後も6本として残る |

入力平面6本以上の346画像には、全てprior20度の条件を通る方向の組があった。
このデータの失敗を、prior制限だけ、SVDの不具合、後半画像の時間安定判定だけで説明することはできない。

最初に選ぶ方向での一致本数は、2本:8枚、3本:119枚、4本:91枚、5本:101枚、6本:27枚。
**候補10本あっても、それらが同じ鉛直方向を表すとは限らない。**

18代表画像の9,334部分は次の通り。全492画像の統計とは分ける。

| 初めに該当した見送り/採用理由 | 部分数 |
|---|---:|
| 30実観測画素未満 | 8,340 |
| nativeの縦長条件を満たさない | 106 |
| nativeの縦方向spanが60 px未満 | 12 |
| 平面としては通るが同方向の重複 | 721 |
| 独立な方向として保持 | 155 |

この代表集合では、形状条件を通過した876部分は全て平面誤差条件も通過し、そこから重複除去で155方向になった。
9,334部分や876部分を、そのまま独立した物理的な鉛直線数と呼ばない。

座標例：静止中央1.3 mのframe152では、`[194,112]→[272,269]`の線は画像上では縦長だが、
選ばれた診断方向への残差は約27.44度。一方、`[219,193]→[203,300]`は約0.31度、
`[237,222]→[230,300]`はほぼ0度で、ROI下端y=300に達する。
無加工画像では天井方向に延びる線とドア枠を同時に確認できるが、物理鉛直を測量した意味ではない。
この例からは、native上の縦長だけでは方向の意味を区別できず、解析帯の切り方も支持長に影響すると分かる。

## 3. ROI下端だけを変えた対照

監査後に[追加対照の条件](roi_probe_method.md)を固定し、距離ラベルを使わず実施した。
元の`x=40..600, y=60..300`に対し、`x=40..600, y=60..430`の1種類だけを比較した。
native画像を加工したのではなく、処理に使う画素座標の範囲だけを変えている。

角度領域、Hough投票/最大候補200、支持点の選択、平面条件、重複条件、独立6平面、1度の一致、
SVD、priorは固定。parameter化した抽出器のbaselineが、18代表全てで元の画素・normal・採否と一致した。
前半/後半の2画像以上・2度以内の条件も変更していない。

| 録画略称 | 元：前半/後半の有効画像 | 対照：前半/後半の有効画像 | 元→対照の時間再現性 |
|---|---:|---:|---|
| 静止中央1.3 m | 1 / 1 | 11 / 11 | 不足→PASS |
| 静止中央2.0 m | 0 / 1 | 10 / 11 | 不足→PASS |
| 静止左1.3 m | 0 / 1 | 5 / 4 | 不足→PASS |
| コーンなし | 1 / 2 | 6 / 6 | 不足→PASS |
| 静止右1.3 m | 0 / 1 | 2 / 0 | 不足のまま |
| 紙・コーン同一姿勢系列 | 9 / 8 | 1 / 0 | **PASS→不足** |
| 白紙7点 | 0 / 0 | 0 / 0 | 不足のまま |
| 静止中央0.8 m | 1 / 1 | 12 / 12 | 不足→PASS |
| 10/19紙・コーン | 0 / 0 | 1 / 0 | 不足のまま |

画像単位の採用は27→92枚。全492枚の対応は、両方採用8枚・元だけ採用19枚・対照だけ採用84枚・両方見送り381枚。
全件を保存し、元で採用していたのに対照で失敗した画像を消していない。

対照PASS5録画の後半方向の最大離角は約0.21～0.64度。ただし静止左の前半最大離角は約1.87度と、
2度の条件に比較的近い。どのケースも方向の再現性であり、距離誤差ではない。

元の成功系列の17採用画像には、各6本、計102平面観測のinlierがあった。
そのうち**53方向**は、新しい範囲では重複除去**前**の平面条件通過候補にも2度未満の近傍方向がなかった。
重複除去だけで失われたとは説明できず、範囲変更でHough投票・支持点集合・切断・形状/平面適否も変わる。
ただし、最大候補200の上限だけが原因だと特定したわけではない。
この照合は方向の近さであって、同じ物理線を追跡した証明でもない。

## 次に進める範囲と限界

今回の結果は「ROIを広げて本番更新すればよい」ではなく、**画面内の異なる種類の線を一つの投票/支持集合へ
混ぜることが結果を変える**という切り分け。候補の個数を増やすため独立6本を5本へ緩める作業も行わない。

次は、上下の解析帯で候補を混ぜずに持った場合に、同じ方向の根拠が保たれるかを既存画像で検証する範囲がある。
その際も、既存の成功/失敗両方、録画単位の時間分割、距離ラベルを使わない選択、拒否の保持が必要。
この対照結果から都合のよいROIを録画ごとに手選びして、独立評価の成功率とすることはしない。

今回得た方向を距離へ使った比較はまだ実施していない。true vertical、カメラ高さ・heading、床水平、
校正/録画状態、実接地点、遮蔽時の欠測、実時間性・実機安全は未解決の確認事項を引き継ぐ。
追加撮影が必須と特定する根拠にはまだならないので、現時点で撮り直しやターミナル操作は求めない。
