# 10/23継続：保存済み検出枠によるコーン線の除外

## 到達点

**追加推論なしで、コーン検出枠に重なる実観測線を姿勢根拠から除く対照を実装・検証した。**
前回コーン表面由来と疑った8本は、全て同じframeの保存検出枠と重なった。
その8本の実支持画素の約96.7～100%が枠内であり、画像解釈に加えて保存予測との対応も確認できた。
ただし、検出枠は正解領域ではなく、物理的な線の意味や鉛直性を証明するものではない。

コーン枠との重なりと、上側の重複除去前候補との方向近傍を両方考慮すると、採用は28画像・時間再現性1録画。
元の採用27画像は全て保持した。前回の5録画PASSを独立な姿勢根拠の確認としては引き続き採用しない。
距離/TF/FFBへは接続せず、本番設定・実機を変更していない。

## 除外方法

[実行前の固定条件](method.md)に従い、元のclass=0/conf>=0.5の全予測枠を使った。
同一frameのnative xyxy閉区間、padding=0。線の**実観測エッジ画素**が1点でも枠へ入る場合、線全体を見送る。
始終点を結ぶ長方形との重なりだけでは判定せず、枠内部分だけを切り落として再fitする処理もしない。
画像へマスクを描いたり、注釈・切り抜き・リサイズ等を保存したりはしない。

上側/下側の全176画像を再抽出し、native画素hash・元の採否/理由と照合した。
元の帯内重複除去で捨てた候補は復活させない。上下間の重複除去は、残った候補へ従来の優先順で再適用する。
重複前参照も使う系列では、対象枠に重なる上側参照候補も使わない。
保存枠に重なると記録したのは11,001候補行中671行（元採用候補では160行）。
これは独立物理線数ではなく、同方向の重複候補も含む行数である。

## 限界・本番へ反映しない理由

- 枠内の背景線も除外することがあり、枠外には見逃したコーン・人・床などの線が残り得る。
- 枠を外れた線を「背景/建物/鉛直」と分類したわけではなく、全出力の`background_identity_verified=false`を維持する。
- 重複前参照による除外も近い別の実線を過剰に捨てる可能性がある。今回の保守的対照を完成した本番品質ゲートとはしない。
- 条件通過1録画も、物理鉛直・床水平・実接地点・距離の一般精度・安全出力を独立に確認した意味ではない。
- 同じ開発録画を見た後の比較であり、新環境での独立した評価ではない。

## 次の判断

現データでは、対象と重複を考慮したまま自動姿勢の適用範囲を広げられた、とは言えない。
採用数を増やすためのROI/必要本数の再調整を続けず、今の仮説と拒否理由を凍結する。
既存データで続けるなら、同じ連続輪郭の支持点を1票として扱う比較や、
姿勢根拠が不足する録画を測距へ使わず保留する経路の確認が対象になる。
現時点で、ユーザーへ新規録画・実機操作を求める必要はない。
