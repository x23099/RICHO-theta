# 測距の利用条件・保留理由を分離した監査

## 結論

既存の**条件付き診断距離は保持し、物理検証が未確認の距離と混同しない判定台帳**を作成した。
これはオフライン解析用の実験コードで、本番の測距・ROS/TF/FFBへ新しいゲートを追加したものではない。
診断の適用範囲や距離精度を改善した実装でもない。

| 項目 | 結果 |
|---|---:|
| コーン測距台帳 | 8録画・6,876 unique frame |
| 比較方式 | 2方式、計13,752行を全て保持 |
| 診断条件を満たすframe | 各方式1,107 / 6,876 |
| 診断条件不足で保留 | 各方式5,769 / 6,876 |
| 従来の診断値・採否との相違 | **0件** |
| 物理確認条件を一式満たす行 | 0（未確認を合格へ昇格しない） |
| 画像加工・新しい幾何計算・本番設定変更・実機出力 | なし |

2方式は同じframeに対する対照であり、独立した2倍の実験数ではない。
物理条件0件はカメラや床接地点が誤っている証明ではなく、必要な確認記録が一式揃っていないという意味。
既存の青箱FFB経路の過去の実機成功を取り消す判定でもない。

## 診断値と物理根拠の分離

[方法](method.md)に条件を固定し、[純粋関数](eligibility.py)でframeごとの証拠から判定する。

| 欄 | 用途・条件 |
|---|---|
| `audited_raw_forward_m` | 有限な生計算値を監査用に保持。拒否した外れ値を含み、出力距離ではない |
| `offline_diagnostic_distance_m` | 出典・同一frame結合・native座標・校正候補・録画自身の姿勢候補・当該観測・画像品質・有効床交点が揃う場合のみ |
| `physically_supported_distance_m` | 診断条件に加え、内部校正の運用受入・録画ごとの外部姿勢・実接地点・距離不確かさの確認が揃う場合のみ。今回の実データでは全て空欄 |
| `diagnostic_blockers_json` / `physical_blockers_json` | 不足する根拠を層別に**全件**記録。最初の理由だけには絞らない |

欠測/画像品質不足/録画自身の姿勢不足を、以前の距離・他録画の姿勢で補わない。
非有限・ゼロ・負の前後距離も診断に使わない。保留から「障害物なし」「安全」を推論しない。
全条件が揃う合成テストであっても`realtime_ready=false`・`usable_for_ffb=false`固定。
実測の証拠を取得・判定するAPIや安全承認器ではない。

## 保留理由と残る根拠

各方式6,876 frameに対し、録画自身の姿勢不足5,329、当該色端点なし1,907、画像品質見送り2,078、
床交点なし/前後距離なし5,734。**同じframeが複数理由を持つので、合計して保留frame数にはしない。**
[理由別CSV](results_r01/blocking_reasons.csv)と[全frame判定](results_r01/frame_decisions.csv)を対応させた。

物理確認に必要な4項目は[根拠一覧](results_r01/physical_requirements.csv)に分けた。
小さい再投影誤差、建物線の時間安定、色支持の連続、数cmの距離中央値差から自動的に確認済みにはしない。
経験的な姿勢変動の距離範囲を信頼区間としても使わない。
現時点で追加撮影を必須とは判断せず、新しい録画を依頼していない。
