比較tap P95は約0.033ms。両比較workerはsetupを含む161行ずつを処理し、500ms鮮度の範囲内で終了した。フレームの頻度制限・近似・前フレームキャッシュは追加していない。

件数/秒は320測定行÷2 blockの経過秒合計、P50/P95はnearest-rank。GPU・torch/CUDA・numpy/OpenCV/ultralyticsの記録バージョン、元入力・重みのSHAはr03と同じ。ただし温度・電力制限・他プロセス負荷などの同時測定はないため、差の全てを今回の変更だけへ厳密に帰属させない。`predict_ms` はCPU待ち等も含む呼出しwall時間で、GPUカーネルそのものが高速化した証明にはしない。

8枚を上限30回/秒で反復した保存画像試験である。producerが遅れに応じて待つため、独立した実カメラ30fps入力のdrop・通信・表示・操縦への影響はまだ別確認。モデル初期化約2945ms、warmup初回約1009msは測定分布から除外済み。
