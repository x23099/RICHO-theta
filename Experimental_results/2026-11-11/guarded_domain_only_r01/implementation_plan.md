# bool有効域チェックから不要なray逆算を除く

2026-11-11。単純比較間引きは保存ログで数値機会40→1となるため採用しない。代わりに、捨てているrayの計算をなくす局所的な意味保存リファクタリングを行う。

- 既存 `unproject` は前半で校正型・画像サイズ・有限Nx2・ROI・最大半径を検証し、その後にrayを64回二分法で逆算する。観測のbbox／context／候補中心チェックはboolだけを使い、rayは捨てている。
- 同じ前半をprivate helperへ分け、`pixels_in_domain` が同じvalid maskだけを返す。実際の支持点のrayが必要な `unproject` は同じ64回・同じ式を維持する。点・画像・bboxの丸め、校正・最大角・床法線・距離式、閾値は変えない。
- 変更する呼出しはboolだけを使用している4モジュール（core、colour seed、lateral context、upper context）へ限定する。キャッシュ、フレーム間共有、比較間引き、camera/ROS/FFB/制御接続は追加しない。
- 固定した変更前の式とのvalid/rayのbit単位一致、境界・不正入力・空配列・重複・float/整数の検証、既存観測／距離／失効回帰を行う。保存画像の主結果・比較値も再現する。
- CPU計測では比較用にbool関数を元の `unproject(...)[1]` へ差し替えたreference経路と、bool専用経路をABBAで比較する。差し替えは単独の計測プロセス内だけで行い、runtimeは常に正規のbool関数を使用する。実CUDAや実カメラ性能とは呼ばない。
- 合格した差分だけGPU PCへ渡し、間引きなしの既存CUDA試験をr04へ保存して確認してもらう。新しい撮影・寸法測定・走行は不要。commit/pushは今回依頼されていないため行わない。

## 検証後の補足

404テスト成功、元8ケース全値一致、r03比較320行一致、実子／pipe再生成功。CPU ABBAはP50 49.14→33.15ms。実GPU効果は未確認。今回変更するcolourモジュールがGPU試験の依存SHA一覧に欠けていたため、測定処理を変えず記録対象へ1件追加し、影響する22テストのみ再実行した。転送はruntime5＋測定メタデータ1＋新規テスト1＋資料／生成器3の10ファイルに限定する。
