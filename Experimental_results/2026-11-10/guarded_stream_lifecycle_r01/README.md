# 比較専用ストリームの参照管理・失効を実装

2026-11-10。**同じ接続内で観測した参照だけを、明示読込み後の画像に適用する管理部分を実装・検証した。** GPU PCの録画後比較一致確認からの次段階。既存の測距・運転画面・操縦経路にはまだ接続していない。現在の走行測距は従来どおりで、改良候補のリアルタイム実機表示は未完了。

## 実装した範囲

[cone_guarded_stream_comparison.py](../../../src/cone_guarded_stream_comparison.py) の `GuardedStreamComparison`。新しい幾何・検出器ではなく、検証済みの自己領域棄却＋bbox下端半画素候補に対する、比較専用の状態管理。旧オフライン実装や過去の照合SHAを書換えていない。

```text
処理対象のsession/frame/受信時刻をadmit
  → 明示保存対象の元画素digestをpin（最大8件、画像履歴は保持しない）
  → 同sessionの参照JSON＋PNGを明示activate
      → 元PNG SHAと、復号画素がpinした画素に一致することを確認
      → activate時点より後のframeだけ別の比較結果を生成
  → 切断／再接続／0.5秒超の入力間隔・鮮度切れ／不正入力で失効
```

- 外から `reference_matches=True` と宣言するだけでは有効化できない。既存オフライン参照JSONを読めるが、過去の別接続のものは拒否。session書換えだけでもpin済み画素照合が残る。
- load要求時に旧比較値を先に消す。失敗時に旧世代へ戻さない。旧sessionの遅延到着も再開に使わない。
- 元結果のsession/frame/受信時刻、profile、未承認flagを照合。比較を行うときは元の観測・距離・モデル結果を再現できることも確認する。
- 左右・上端の緩和や整数化fallbackは追加しない。隠れた接地点を補完せず、自己領域に触れる支持範囲を保留する。
- 比較処理の所要時間を含めて受信後0.5秒を超えれば数値を消す。時計の巻戻り、比較例外でも比較側だけ失効。古い値の穴埋めはしない。
- 結果は自分のsession/frame/時刻に対応し、後から来た別frameの結果に見せかけない。返却はcopyで、元の画素・検出枠・主判定は変更しない。
- 同時呼出しは非対応。今後の接続では単一ownerへイベントを直列化する。ディスク、GPU推論、ネットワーク、ROS、制御をこのクラスから呼ばない。
- `physical_metric_verified`、`floor_contact_verified`、`controlling_distance`、`usable_for_ffb`、`published_to_ros` は全てfalse。画像対応の一致は、物理接地やカメラ固定状態の保証ではない。
