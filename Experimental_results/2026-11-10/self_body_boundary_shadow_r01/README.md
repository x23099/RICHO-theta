# 天板の自己遮蔽とbbox画素境界の分離（オフライン）

2026-11-10。**同じ支持点を数値化する前に、天板境界へ重なる候補を棄却する比較を追加した。保存8枚では、隠れた台座の候補5枚を通さず、台座が見える14922の候補値はそのまま残せた。** liveの判定・運転・操縦は変更していない。

これは画像上の局所的な棄却仮説であり、自己遮蔽の汎用自動認識や床接地の認定ではない。追加撮影は行わず、既存の [17:12提出物](../driver_motion_171250_review_r01/README.md) を使った。

## 方法・参照の範囲

- 実装: [cone_self_body_shadow.py](../../../src/cone_self_body_shadow.py)。既存の画像支持点チェックを利用し、座標・画像・色閾値・検出枠・校正・距離値を調整しない。live entry pointからのimportはない。
- [参照点](reference.json): session `4c34c8c3d6d44949afb2e921e819e563`、frame 14604の元PNG上で天板上端を暫定的に読み取った。x=260～380の6点だけを折れ線補間する。中央付近はy=458。
- 境界は人手の読み取りであり、自動検出・独立測量ではない。参照PNG SHA、session、1280×720 native座標を照合。余白の既定2pxは読み取りの不確かさを扱う仮説で、距離誤差から最適化した値ではない。
- 候補点だけでなく、観測したsupport全列が天板境界より余白分上にあることを要求。1列でも境界に近い／下に入れば棄却する。範囲外は外挿せず、別session・未照合の参照・不正supportも棄却する。
- 元々点がない判定から点を作らない。clearの場合も元のpoint／support／数値を完全に維持し、接地・精度・制御の権限を付けない。
- 14604は参照作成に使用したので独立検証枚数に含めない。保存8枚のうち7枚が参照作成に使っていない画像。ただし少数・同sessionの解析者レビューであり、独立した正解データセットではない。

raw PNGは `recordings/2026-11-10/driver_motion_171250_intake_r01/motion_withheld_20261110_171250/`。画像の切抜き・注釈・リサイズ・画素変更は行っていない。参照点と [目視所見](visual_review.json) は別JSONに保存した。
