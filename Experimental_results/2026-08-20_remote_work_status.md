## 左右非対称の追加診断

P0-Bでは、同じ真値`z=1.0 m`に置いた左側の正規化面積中央値が`2172.5`、右側が
`2759.5`で、左/右比は`0.787`だった。正規化面積は概ね`area_px * z^2`で計算する。
P0-Bの推定z中央値`0.9575 m`と`1.0529 m`から得る`z^2`の左/右比は`0.827`である。
一方、中央値から逆算した生面積は約`2370 px`と`2489 px`で、左/右比は約`0.952`に
とどまる。

したがって、左だけがしきい値`2503.678`を下回る主な機構は、青領域そのものが大幅に
小さいことより、左右で異なるz推定を二乗して面積へ掛けることにある可能性が高い。
P0-Aでも真値`z=0.95 m`の左右推定zは`0.9046 m`と`1.0208 m`で、その二乗比
`0.785`はP0-Bの正規化面積比`0.787`とほぼ一致する。ただし、これは集計中央値からの
推論であり、フレーム単位の確定診断ではない。

今回のholdoutを見てしきい値を下げると評価データへの後合わせになるため、設定値は
変更しない。追加した診断CLIで元CSVをフレーム単位に集計してから、別日の独立した
左右静止録画で再現性を確認する。

### ライブ試行完全性の自動評価

録画本体を使わず、既存の`2026-08-18_p0b_live_trial_summary.csv`へ検出率、観測採用率、
追跡率、警告率の要件を適用した。4条件中、青箱なし、中央静止、右静止はPASSし、左静止は
観測採用率0%、追跡率0%のためFAILとなった。これにより、未追跡による警告率0%を正常な
経路外判定として扱わないことを自動化した。これはP0-Bの「静止時誤発火なし」という既存の
判定を変更するものではなく、後続の経路判定へ使用できるデータの完全性を別に判定する。

- 要件: `Experimental_results/p0b_live_trial_completeness_requirements.csv`
- 結果: `Experimental_results/2026-08-20_p0b_live_trial_completeness.csv`
- 評価CLI: `src/evaluate_live_trial_requirements.py`

同じ評価CLIを速度、TTC、警告フレーム数、ヒステリシス遷移へ拡張し、P0-Cにも適用した。

| 自動評価 | 結果 |
|---|---|
| P0-A 7地点の検出・観測・追跡・ODOM・平均/最大位置誤差 | PASS |
| 0.10 m/s接近の方向・速度・TTC | PASS |
| 0.10 m/s後退の方向・速度・TTC誤発火 | PASS |
| 0.20 m/s接近の全3試行で警告あり | PASS |

| P0-B静止時のヒステリシス誤警告なし | PASS |
| P0-C 0.10 m/sのヒステリシス誤警告なし | PASS |
| P0-C 0.20 m/sの警告保持・0.5秒以内の成立・前進中PATH復帰なし・最終CLEAR | PASS |

0.20 m/s全区間評価では3/3試行の方向正解率が95%未満で、3/3試行の速度MAEが
0.032 m/sを超えた。このFAILと、3/3試行の警告発生PASSを別ルールにしたため、初回警告の
成功で近距離側の位置反転を隠さずに判定できる。`UNKNOWN`の発生数には上限を設けておらず、
`UNKNOWN`を安全または合格の証拠として扱っていない。

## リモートで進める順序

1. 既存P0-Bアーカイブを直接読み、左右の生面積、z、正規化面積の比を確定する。
2. 全単体テストとpreflightのハードウェア非依存項目を実行する。
3. 既存P0-C録画で警告ヒステリシス回帰を維持する。
4. 次に登校・現地対応できる日に、ロボットを動かさず左右`x=±0.40 m, z=1.0 m`を
   独立録画する。
5. その結果を見て、方位角を含む位置校正または観測ゲート正規化の設計を検討する。

P0-Bアーカイブが学校PC上の既報パスにある場合、展開せず次を実行できる。

```bash
cd ~/theta_ws/RICHO-theta
python3 src/diagnose_lateral_gate_asymmetry.py \
  --input /home/hsr/Downloads/recoding/recoding_08181700.tar.xz \
  --output Experimental_results/2026-08-20_p0b_lateral_gate_diagnosis.csv
```

アーカイブの所在が異なる場合は`--input`だけを実在パスへ変更する。診断CLIはアーカイブを
展開せず読み取り、元データを変更しない。
