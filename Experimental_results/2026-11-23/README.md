- **Δ=0.05が最も安定**（符号反転3、揺れ0）だが、デッドバンド内が82.5%に増える。
- Δ=0.15は方向が出やすいが、符号反転7・揺れ4。
- **予測時間1.5 sと3.5 sで結果が同一**。経路が最低距離まで延長されるため、この範囲ではホライズンの影響が出ていない。

## 4. 結論

1. 実距離系列のフレーム間揺れはmm級で、**3連続一致が方向反転を完全に抑える**（確定後0）。
2. ただし**同側yawでの符号反転はΔを小さくしても残る**（3/80）。リスク関数の境界（corridor二値・eta）に起因する可能性が高く、Δ調整だけでは解消しない。
3. デッドバンド内の割合が高く、`direction`だけを送る方式では方向情報が乏しい。**Δ=0.05〜0.10で安定性を優先**し、大きさのみ提示との併用を検討する。
4. 予測時間はこの条件では効かない。より長いホライズンや連続リスク化は別途比較が必要。

## 6. 連続リスク・経路打ち切りの比較（符号反転の機序）

[run.py](continuous_risk_r01/run.py) / [結果](continuous_risk_r01/results_r01/comparison.json)

同側yawの符号反転を、corridor二値のせいと仮定して3案を比較した。

| 方式 | デッドバンド内 | 側と符号逆 | ±1 cmで方向変化 |
|---|---:|---:|---:|
| 既存（corridor二値＋eta） | 62 / 80 | 6 | 0 |
| 連続clearance（sigmoid×urgency） | 56 / 80 | 8 | 1 |
| 経路を障害物前方で打ち切り（二値） | 62 / 80 | 6 | 0 |
| 打ち切り＋連続 | 56 / 80 | 8 | 1 |

**どれも符号反転を減らさなかった。** 機序をclearanceで確認した（1.0 m左25 cm、0.4 m/s、yaw+0.3の3経路）。

| ω | clearance | corridor |
|---:|---:|---|
| 0.15 | **−0.154 m** | True（車体幅内） |
| 0.30 | +0.014 m | True |
| 0.45 | **+0.182 m** | False |

強い左旋回では、予測経路がコーンの**左側を回り込む**ためclearanceが増える。したがって「さらに左へ切る方が安全、戻す方が危険」という勾配は**幾何的に正しい**。corridor二値のアーティファクトではなく、連続化しても消えない。

**解釈の訂正**：ドライランで数えた「コーンの側と符号が逆」は、単純な「コーンの側＝危険」という期待との不一致であって、モデルの誤りではない。計画書4.1の「操舵に対するリスクの感度」としては整合している。論点は**制御則がこの感度をどう提示したいか**であり、リスク関数の平滑化では解決しない。

## 7. B案（側ベース＋勾配は大きさ）の実装と比較

[実装](../../../src/driver_ffb_side_mapping.py) / [テスト](../../../tests/test_driver_ffb_side_mapping.py) / [比較](side_mapping_r01/results_r01/comparison.json)

- 方向：障害物の側（`left_m`の符号、±0.05 mのデッドバンド）。左なら`-1`（左切れ抵抗）、右なら`+1`。
- 大きさ：`risk_level`の基礎値（WARNING 0.25 / CRITICAL 0.40 / UNKNOWN 0.15）× `(1 + 0.6·|g|)`。`|g|≤0.1`では変調しない。
- **勾配は方向を変えない。** 強い同側旋回で勾配が逆転しても、方向は障害物の側のまま。
- 中央（|left|≤0.05）は方向0で基礎大きさのみ。無効・CLEAR/PATHは0。
- ROS/G923/FFBへ未接続、全authority flags false。

### A（生の勾配方向）との比較（80評価）

| 指標 | A | B |
|---|---:|---:|
| 障害物の側と方向が不一致 | **6 / 80** | **0 / 80** |
| 方向の内訳（左/なし/右） | 9 / 62 / 9 | 4 / 74 / 2 |
| 大きさの範囲 | — | 0〜0.40 |

- Aの不一致6件はすべてBで解消。幾何反転の影響を方向に出さない。
- Bの方向0が多いのは、中央配置とCLEAR/PATH（非活動）を含むため。活動時は障害物の側だけを向く。

### 設計上の未決

1. **risk_levelの出所**：中心経路のcorridor/etaから`classify_candidate_risk`で算出。実運用では既存のリスク段階を使う。
2. **中央時の提示**：方向0で基礎大きさのみ。周期effectで大きさだけ出すか、0にするかは実機の知覚で決める。
3. **側のデッドバンド**：±0.05 m。コーンが正面至近のときの左右判定に相当。実測の横分解能と合わせて調整が必要。
4. **大きさ変調の向き**：`|g|`で増やす設計。危険側の感度が高いほど重くなるが、上限1.0でクランプ。
